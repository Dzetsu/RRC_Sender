# RRC_Sender
В данном веб-приложении реализована микросервисная архитектура подходом Choreography  <!-- описание репозитория -->

## Для чего создавалось?
Данное маленькое веб-приложение создавалось для отработки навыков использования: Kafka, Docker, Docker Compose, Liquibase, PostgreSQL, а также чтобы попробовать реализовать архитектурный подход Choreography и паттерн Transactional outbox
